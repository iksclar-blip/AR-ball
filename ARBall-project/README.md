# AR Ball – כדור מציאות רבודה עם בעיטה ביד

## איך מקבלים APK (בלי לכתוב קוד)
1. היכנס ל-https://github.com (אפשר להירשם בחינם) ולחץ New repository (מאגר חדש, שם חופשי).
2. בדף המאגר לחץ "uploading an existing file" וגרור פנימה את **כל התוכן** של התיקייה ARBall
   (כולל התיקייה המוסתרת .github). חשוב: הקבצים עצמם, לא ה-zip.
3. לחץ Commit changes.
4. עבור ללשונית **Actions** – תהליך "Build APK" ירוץ אוטומטית (כ-5–8 דקות).
5. בסיום, היכנס להרצה ובתחתית הדף, תחת Artifacts, הורד את **AR-Ball-APK**.
6. חלץ את ה-zip, העבר את app-debug.apk לטלפון והתקן (יש לאשר "התקנה ממקורות לא ידועים").

## שימוש
- דרוש טלפון אנדרואיד התומך ב-ARCore (Google Play Services for AR).
- כוון את המצלמה לרצפה/שולחן והזז לאט – אחרי רגע הכדור ייפול למקומו.
- הושט יד מול המצלמה ועבור במהירות על הכדור כדי לבעוט בו. קצב וכיוון הבעיטה נקבעים לפי תנועת היד.
- הכפתור "אפס כדור" מציב את הכדור מחדש במקום שאליו מכוונת המצלמה.
- הטקסט בראש המסך מציג נתוני זיהוי יד (לכיול).
